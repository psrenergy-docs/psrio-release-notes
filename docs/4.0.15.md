## 4.0.15 (2026-08-12)

### Added
- `dashboard:push_divider()` — a hairline separating first-level tabs in the sidebar.
- `dashboard:push_divider(label)` — the same separator rendered as a section caption, with the hairline filling the rest of the line. The caption is hidden when the sidebar is collapsed.

### Fixed
- Tabs nested more than two levels deep are no longer dropped from the dashboard. A tab pushed into another tab is now always stored as a leaf: whatever it already carried below itself is promoted to a sibling, and the name of the dissolved group is prefixed onto the promoted title, so `Simulation` inside `Solution quality` becomes `Solution quality - Simulation`. Previously those sub-tabs were absent from the sidebar and their charts were written to the page with no container to render into.
- Sub-tabs marked with `tab:set_disabled()` no longer render a navigation button. The button had no panel behind it and opened a blank page.
