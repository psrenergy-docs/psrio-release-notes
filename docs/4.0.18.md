## 4.0.18 (2026-09-01)

### Added
- `Hydro().storage_x_turbining__storage(point)` and `Hydro().storage_x_turbining__max_turbining(point)` for accessing the points of the storage × turbining table. Existing storage × elevation table attributes remain available.

### Fixed
- `to_block()` and `to_hour()` now work in `--model none` by loading the hour-block mapping from `hblock` and the stage durations from `duraci` instead of depending on a loaded study.
- `require` and `include` now load Lua files only from approved locations. `require` searches PSRIO-base, the output folder when `-o` is provided, and the case paths, while preserving Lua's native module-cache behavior. Native libraries and path traversal are blocked.
