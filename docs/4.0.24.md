## 4.0.24 (2026-09-30)

### Added
- SDDP output loading support for the additional PSRIO collections.

### Fixed
- Dashboard uploads now use a dedicated S3 client in `us-east-1` for both the standard and Vue dashboards.
- The `AWS_UPLOAD_PSRIO_DASHBOARDS_BUCKET` override remains supported, with `psrio-dashboards` as the default bucket.
