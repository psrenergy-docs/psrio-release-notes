## 4.0.29 (2026-11-23)

### Fixed
- Crash (segmentation fault) when using `BY_AVERAGE_EXCLUDING` in `aggregate_agents` to aggregate agents into another collection (e.g. `renewable` into `bus`). The function now computes the simple average of the agents whose value is different from the excluded value.
