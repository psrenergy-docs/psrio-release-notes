## 5.0.0-rc28 (2026-11-12)

### Added
- `Shunt` collection
- `StaticVarCompensator` collection
- `SynchronousCompensator` collection
- `exp:aggregate_blocks(function, {block1, block2, ...})`
- `exp:aggregate_blocks({block1, block2, ...})`
- `BY_EXCLUDING_KEEP_NAN(nil)`, which preserves `NaN` when every value is excluded and otherwise applies the regular unit-aware aggregation
- `exp:aggregate_scenarios(function, {scenario1, scenario2, ...})`
- `exp:blocks_to_agents(...)`
- `exp:flowcontroller_from(...)`
- `exp:flowcontroller_to(...)`
- `exp:hour_discretization(...)`
- `exp:save_and_load(...)`
- `exp:scenarios_percentile_indexes_range(...)`
- `exp:scenarios_percentile_indexes_right(...)`
- `exp:scenarios_to_agents(...)`
- `exp:select_scenario_per_stage(...)`
- `exp:select_scenarios_by_simulation_index({scenario1, ...})`, which maps original simulation indexes from `IndexSeriesSimulacao` to output scenario indexes; it warns when the mapping is unavailable and rejects indexes not selected in the study
- `exp:select_agents({agent1, ...}, separator)`, which can select agents grouped by the part of their name before the separator while preserving exact agent-name selection
- `exp:select_stages_by_year_period(...)`
- `exp:sort_scenarios_ascending(...)`
- `exp:sort_scenarios_descending(...)`
- `exp:to_block_origin(...)`
- `exp:to_hour_origin(...)`
- `exp:vertices(...)`
- PSRPlot `category_block` x-axes with shared metadata through `chart.xAxes` and `xAxisId`
- `chart:add_errorbar_block_categories(lower, upper, options)`
- `chart:add_errorbar_block_categories_parallel(lower, upper, options)`
- PSRPlot horizontal legends with fixed reserved space, horizontal and vertical centering, and automatic Highcharts pagination
- `collection:load_baseline(file)`, which loads a file only from the baseline path set by `PSRIO_set_baseline_path` and raises an error when it is missing, so a comparison never falls back to the current output
- `--without_fatal_errors` option, which makes failures throw `std::runtime_error` instead of ending the process, so a host that embeds PSRIO can keep running
- `PSRIO_set_baseline_path(path)` and `PSRIO_report_errors()` in the `psrio_lib.h` C API. The error count accumulated by `Compare` and `Report` must be read before `PSRIO_finalize()`

### Changed
- `--MD_execution` now only selects the PSRDataManagement mask files; it no longer makes failures throw. Use `--without_fatal_errors` for that
- `Compare` lists at most the first differences but now scans the whole series, and reports how many were not listed and the total number of differences

### Fixed
- Legacy `indice.grf` parsing now preserves the first character of the agent class.
- `load_table` and `load_table_without_header` now prioritize the output path when `--load_from_output_path` is enabled and fall back to the case path. Their boolean parameter now requires the file to exist when set to `true`; otherwise, missing files log an error and return an empty table. Directories are no longer treated as input files.
- PSRPlot charts and JSON outputs now preserve the original scenario and block indexes after selections, so labels and tooltips show the selected study indexes instead of compact positions
